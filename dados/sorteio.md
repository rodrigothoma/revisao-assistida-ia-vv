# Sorteio dos revisores entre os códigos R1 a R4

O sorteio foi feito em 26/10/2026, pedindo ao assistente Claude Sonnet 5.5 uma ordem aleatória para os quatro revisores. A resposta veio em texto, sem execução de código, então não há semente nem garantia de aleatoriedade. Cada revisor manteve o código sorteado quando o quadrado latino (Tabela 1 do artigo) foi revisado, em 10/11/2026.

O vínculo entre nome e código fica só com os preparadores e não é publicado.
