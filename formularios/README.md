# Formulários do experimento

Cópias em PDF dos formulários usados na coleta de 11/11/2026 e do roteiro lido pelos revisores. Todas as versões de revisão têm a mesma estrutura; mudam a imagem do código e, nas versões L1 e L2, as duas sugestões (texto também em `cenarios/C<n>/sugestoes/listas.md`). Nenhum formulário coletava nome ou e-mail: o revisor era identificado só pelo código R1 a R4.

| Arquivo | Conteúdo |
|---|---|
| `roteiro.pdf` | Instruções e exemplo lidos antes da largada (sem os links pessoais) |
| `CARACTERIZACAO.pdf` | Questionário de caracterização |
| `C1-H.pdf`, `C2-H.pdf`, `C3-H.pdf`, `C4-H.pdf` | Revisão sem assistência |
| `C1-L1.pdf` … `C4-L1.pdf` | Revisão assistida, lista L1 (sugestão de D1 + falso positivo na posição 2) |
| `C1-L2.pdf` … `C4-L2.pdf` | Revisão assistida, lista L2 (falso positivo na posição 1 + sugestão de D2) |
